Modelo C4

La arquitectura de microservicios en tres niveles de zoom: contexto, contenedores y componentes.

Nivel 1

Contexto del sistema

Interacción a alto nivel entre los usuarios, nuestra plataforma y los sistemas externos.

Vecino

[Persona]

Busca y aparta productos baratos para evitar su desperdicio.

Comercio

[Persona]

Publica el inventario próximo a vencer con descuento.

Administrador

[Persona]

Verifica comercios y modera el contenido.

⬇

ResqApp

[Sistema de Software]

Plataforma de microservicios que conecta comercios con vecinos y mide el impacto medioambiental (CO₂).

⬇

AWS Cognito

[Sistema Externo]

Gestión de identidades y autenticación.

Google Maps

[Sistema Externo]

Geolocalización de comercios y rutas.

Cloudinary

[Sistema Externo]

Almacenamiento y optimización de imágenes.

Nivel 2

Contenedores

Zoom dentro del bloque "ResqApp". Se aprecian las aplicaciones cliente interactuando con el Gateway, los microservicios y el bus de eventos.

App Móvil (React Native)

[Contenedor: Mobile App]

Interfaz para vecinos (compradores).

App Web (Next.js)

[Contenedor: SPA]

Interfaz y panel para comercios.

⬇ REST / WebSockets ⬇

API Gateway (Kong)

Enrutamiento, SSL, Rate Limiting

Auth Service

[Microservicio: Node.js]

Roles, Permisos y Sesión.

DB: Redis

Lots Service (Zoom)

[Microservicio: Spring Boot]

Inventario, Precios y Fechas.

DB: PostgreSQL

Chat Service

[Microservicio: Go]

Mensajería en tiempo real.

DB: MongoDB

Impact Service

[Microservicio: Python]

Cálculo de CO₂ y analíticas.

DB: PostgreSQL

Event Bus (Kafka / RabbitMQ)

Canal de comunicación asíncrono inter-servicios

Nivel 3

Componentes (Zoom en Lots Service)

Zoom dentro del contenedor "Lots Service" mostrando su estructura interna basada en arquitectura limpia / hexagonal.

LotController

[Spring REST Controller]

Expone endpoints HTTP genéricos para publicar lotes.

➡

LotService

[Business Logic Component]

EventPublisher

[Messaging Component]

Publica "LotCreated" al Bus.

➡

LotRepository

[Spring Data JPA]

Mapeo O/R y acceso a datos.
